Nanopore sequencing · CTC decoder demo

Explore greedy Connectionist Temporal Classification (CTC) decoding of model-output DNA probabilities. All calculations occur locally in the browser; no file is uploaded.

Scope: This demo does not ingest raw nanopore ionic current, train or run a neural signal model, call modified bases, or produce validated clinical results. The separate QC audit is a rule-based demonstration, not a laboratory standard.

1 · Decode timestep probabilities

Enter a JSON 2D array or CSV. Each row: blank,A,C,G,T; all five probabilities must sum to 1. Repeated symbols collapse unless separated by a blank.

Run the example to see the DNA sequence.

2 · Rule-based QC audit

A transparent local approximation of the repository's legacy threshold audit. It does not assess raw sequencing quality.

Run the threshold audit to see alerts.
